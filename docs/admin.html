Fotografie realizací

Přidejte nebo smažte fotografie v sekci Realizace. Po uložení se objeví na živém webu (Supabase) — stačí obnovit stránku.

Chybí konfigurace Supabase. Zkontrolujte js/supabase-config.js (URL + publishable klíč) nebo proměnné VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY. Postup: VANILLA-GALLERY.md.

Přihlášení správce

Heslo je účet v Supabase Authentication (e-mail + heslo). Veřejná registrace je vypnutá — účet založíte v Dashboard → Users.

Přidat fotografii

Pokud prohlížeč nemůže soubor stáhnout (CORS), uložíme odkaz přímo — obrázek musí být veřejně dostupný.

Fotografie se zobrazí v sekci Realizace pod zvoleným filtrem. Statické fotky z webu (photos123) se zde nesmažou — spravují se jen nahrávky ze Supabase.
