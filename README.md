# ProTile CZ

Marketingový web společnosti **ProTile CZ s.r.o.** — profesionální pokládka obkladů a dlažeb a dokončovací práce.

- Doména: [protile.cz](https://protile.cz)
- Stack: React + Vite, GitHub Pages
- Jazyk: čeština

## Vývoj

```bash
npm ci
npm run dev
```

## Build / publish

```bash
npm run build
```

Skript `scripts/sync-pages.js` zkopíruje výstup do kořene repozitáře a `docs/` pro GitHub Pages.
